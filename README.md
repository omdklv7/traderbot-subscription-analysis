# TraderBot Subscription Analysis

## О проекте

Пет-проект по бизнес- и системному анализу внедрения подписочной модели TraderBot.

Проект основан на интервью с владельцем продукта, личном пользовательском опыте и официальной документации.

## Цель

Проанализировать переход от бессрочной лицензии к гибридной модели, включающей подписку, и описать изменения в процессах, требованиях и пользовательском опыте.

## Планируемые артефакты

- Project Overview
- анализ стейкхолдеров
- процессы AS-IS и TO-BE
- бизнес- и пользовательские требования
- бизнес-правила
- Use Cases
- модель данных
- SQL- и Python-анализ
- аналитический дашборд
