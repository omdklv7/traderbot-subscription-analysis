Бизнес-анализ перехода TraderBot от бессрочных лицензий к подписочной модели: процессы AS-IS/TO-BE, требования, SQL и Python-аналитика.

# TraderBot Subscription Analysis

## О проекте

Пет-проект по бизнес- и продуктовой аналитике, посвящённый внедрению подписочной модели TraderBot.

Ранее пользователь приобретал бессрочную лицензию стоимостью от $550 и самостоятельно обслуживал серверную инфраструктуру. В новой модели доступ предоставляется по подписке за $50 в месяц, а серверы, обновления и техническое сопровождение находятся на стороне TraderBot.

## Цель проекта

Проанализировать лицензионную и подписочную модели, описать процессы AS-IS и TO-BE, определить требования, бизнес-правила, риски и метрики эффективности.

## В проекте будут использованы

- BPMN
- UML
- SQL
- Python
- аналитика подписочной модели
- синтетические данные
- визуализация и дашборд

## Источники информации

- интервью с владельцем TraderBot;
- личный пользовательский опыт;
- официальная документация;
- аналитические допущения.
